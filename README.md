# Bakugan: Battle Planet Wiki & Database

> Plataforma web informativa desenvolvida para catalogação, consulta de atributos e gerenciamento de cartas/personagens da franquia *Bakugan: Battle Planet*.

---

##  Sobre o Projeto

Este projeto nasceu como uma ferramenta para centralizar e organizar dados, cartas, atributos e estratégias do universo de **Bakugan: Battle Planet**. A proposta é servir como uma wiki dinâmica, intuitiva e acessível para jogadores e fãs da franquia consultarem informações de forma rápida.

O projeto está atualmente em fase de expansão e implementação de novos recursos.

---

##  Funcionalidades

- [x] **Listagem de Bakugans:** Visualização de personagens organizados por facções (Pyrus, Aquos, Ventus, Haos, Darkus, Aurelus).
- [x] **Fichas Detalhadas:** Consulta de estatísticas básicas (B-Power, Dano, Requisitos e Efeitos).
- [ ] **Filtros Avançados:** Busca dinâmica por atributos, facção e tipo de carta *(em desenvolvimento)*.
- [ ] **Deck Builder / Gerenciador de Coleção:** Interface para montagem de equipes e decks personalizados *(planejado)*.

---

##  Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas.
- **CSS3 / Flexbox / Grid:** Estilização visual temática e layout responsivo.
- **JavaScript (ES6+):** Manipulação dinâmica do DOM, filtragem de dados e interatividade.
